## ✨ المميزات

كل ما يحتاجه المدرس الخصوصي لإدارة مركزه التعليمي:

**📊 الرئيسي**
- **لوحة التحكم** — 9 مؤشرات (الطلاب، الحضور، المتحصلات، المصروفات، الصافي، المستحقات…)، جلسات اليوم، أعلى المديونين، رسوم الاتجاهات المالية، المهارات الضعيفة، مقارنة بالشهر السابق
- **الطلاب** — إضافة وتعديل مع تحقق، بحث وفلاتر، تاريخ التسجيل، بيانات ولي الأمر، وصفحة خاصة لكل طالب
- **الحضور** — كشف يومي (يقتصر تلقائياً على مجموعات اليوم)، عرض شهري، 4 حالات (حاضر / متأخر / غائب / معذور)، زر تحديد الكل حاضر، طباعة الكشف PDF
- **المجموعات** — إدارة كاملة بالأعضاء وتاريخ بدء اختياري، ومحرر للحصص الأسبوعية داخل نموذج المجموعة نفسه

**💰 المالية**
- **المدفوعات** — مستحقات شهرية (الطالب يُحسب مرة واحدة)، سجل المدفوعات، إيصال دفع PDF لكل عملية، كشف حساب لكل طالب
- **المصروفات** — التكاليف الخارجة حسب الفئة (جوائز، أدوات، مرافق، صيانة، أخرى) مع إجمالي شهري ورسم دائري للفئات

**📚 الأكاديمي**
- **الواجبات** — إسناد لكل مجموعة، متابعة التسليم، نسبة الإنجاز
- **الامتحانات** — إنشاء، إدخال الدرجات، متوسط / أعلى / أقل درجة
- **المهارات ونقاط الضعف** — درجات المهارات لكل طالب + نقاط ضعف نصية مع متابعة الإنجاز
- **الجدول** — شبكة الحصص الأسبوعية (عرض يومي/بالمجموعة، تنقل بين الأسابيع، كشف تعارض القاعات)، حصص ليوم واحد، إلغاء أو نقل حصة واحدة (نفس اليوم أو يوم آخر) مع استعادة

**📈 التحليلات والنظام**
- **صفحة الطالب** — إحصائيات، رسوم الاتجاهات (الحضور، الامتحانات، الواجبات، المدفوعات)، كشف الحساب، بطاقة التقرير PDF، سجل النشاط
- **التقارير** — الطلاب، الحضور، الامتحانات، المدفوعات، المصروفات، المالية + كشف حساب لكل طالب؛ تصدير Excel و PDF بدعم العربية واتجاه RTL
- **الإشعارات** — مركز محفوظ (واجبات متأخرة، مستحقات غير مدفوعة، تغييرات الجدول، مهارات ضعيفة، حضور منخفض) مع تنبيهات النظام
- **سجل النشاط** — كل تغيير مسجل وقابل للبحث، مع زر **تراجع** عن أي حذف
- **الإعدادات** — 4 ثيمات × فاتح/داكن، وضع تباين عالٍ، ساعة 12/24، بداية الأسبوع، قوالب واتساب، مزامنة Supabase + نسخ سحابي

**⚡ سرعة الاستخدام** — لوحة الأوامر `Ctrl+K`، نوافذ إنشاء سريعة من أي مكان، جرس الإشعارات، شريط جانبي متجاوب.

## 📥 التحميل والتثبيت (للمعلمين)

1. افتح صفحة [**Releases**](https://github.com/MrMostafaMo/teacher-manager/releases) وحمّل النسخة المناسبة لجهازك:
   - **ويندوز** — `.msi` / `.exe`
   - **لينكس** — `.deb` / `.rpm` / `.AppImage`
   - **ماك** — `.dmg` (بمعماريتي `aarch64` و `x86_64`)
2. ثبّت البرنامج وافتح **مدير المعلم** وابدأ بإضافة الطلاب — بدون حساب وبدون إنترنت.
3. قاعدة البيانات محفوظة محلياً بجانب إعدادات التطبيق؛ ويمكنك أخذ نسخة احتياطية في أي وقت من **الإعدادات ← النسخ الاحتياطي** (ملف محلي أو سحابة Supabase).

## 🛠 للمطورين

**المتطلبات:** [Node.js](https://nodejs.org/) (نسخة LTS)، و [pnpm](https://pnpm.io/) بالإصدار `11.21.0`، و [Rust](https://www.rust-lang.org/tools/install) (لأمري `tauri dev` و `tauri build`).

```bash
pnpm install          # تثبيت الاعتماديات
pnpm dev              # سيرفر Vite (الواجهة فقط)
pnpm tauri dev        # تطبيق سطح المكتب في وضع التطوير (المنظومة كاملة)
pnpm build            # فحص طول الملفات + فحص الأنواع + بناء الإنتاج
pnpm tauri build      # بناء ملفات التثبيت (.deb/.rpm/.AppImage على لينكس)
pnpm test             # كل اختبارات الوحدة (vitest)
```

### دورة قاعدة البيانات

المصدر الوحيد للحقيقة هو `src/lib/db/schema.ts`. بعد أي تعديل عليه:

```bash
pnpm db:generate      # drizzle-kit: توليد SQL في drizzle/
pnpm db:sync          # نسخ وتهذيب الترحيلات إلى src-tauri/migrations/
```

ثم أضف `Migration { version: N+1, description, sql }` في `src-tauri/src/lib.rs`. الترحيلات مضمنة في البرنامج وتُطبق تلقائياً عند التشغيل.

### هيكل المشروع

```
src/
├─ app/            # الدخول والمسارات والمزودات وهيكل التطبيق
├─ components/ui/  # مكونات shadcn الأساسية
├─ features/       # مجلد لكل ميزة (students و payments …)
├─ shared/         # مكونات مشتركة: DataTable و Modal و PageHeader …
├─ lib/            # قاعدة البيانات والترجمة والثيمات والإعدادات والتراجع والمزامنة
├─ styles/         # ثيم Tailwind v4 والثيمات (nile/warm/midnight/academy)
src-tauri/         # غلاف Rust والترحيلات المضمنة والصلاحيات
drizzle/           # مصدر ترحيلات drizzle-kit
scripts/           # مزامنة الترحيلات + فاحص طول الملفات
docs/              # المعمارية وخارطة الطريق والصور
```

كل ميزة تتبع `domain.ts` (الكيانات + Zod) ← `application/` (حالات الاستخدام) ← `infrastructure/` (مستودعات Drizzle) ← `ui/` (مكونات React). راجع [`docs/architecture.md`](docs/architecture.md). والقواعد (الترجمة، حد طول الملفات، الاختبارات، RTL) في [`AGENTS.md`](AGENTS.md).

### التقنيات المستخدمة

| الطبقة | الاختيار |
|---|---|
| سطح المكتب | Tauri v2 (ويندوز / لينكس / ماك) |
| الواجهة | React 19 + TypeScript + Vite 8 |
| التصميم | TailwindCSS v4 و shadcn/ui وأيقونات Lucide |
| الحالة | Zustand |
| النماذج | React Hook Form + Zod |

| التوجيه | React Router |
| الترجمة | react-i18next (عربي RTL + إنجليزي LTR) |
| التواريخ | dayjs |
| التصدير | pdf-lib (للـ PDF) و xlsx (للإكسل) |

## 💾 البيانات والمزامنة

- **محلي افتراضياً** — SQLite عبر إضافة Tauri SQL؛ كل الاستعلامات عبر Drizzle (مقيدة المعاملات، بدون SQL خام).
- **النسخ الاحتياطي / الاستعادة** — بضغطة واحدة من الإعدادات (`VACUUM INTO`؛ ملف `.db` وحده آمن للنسخ).
- **مزامنة Supabase اختيارية** — دخول بالبريد وكلمة المرور، دمج بآخر كاتب (last-writer-wins) على مستوى الصف، ونسخ احتياطي سحابي. سياسة التعارض موثقة كآخر-كاتب-يفوز بالتصميم.

## 🧾 التقارير والتصدير

محرك تصدير واحد لكل التقارير إلى **Excel** (أوراق RTL للعربية) و **PDF** (تشكيل عربي وتقطيع ثنائي الاتجاه) — بالإضافة لمستندات خاصة: **إيصالات الدفع**، **بطاقة تقرير الطالب**، **كشف الحساب**، **وكشوف الحضور القابلة للطباعة**، وكلها تُحفظ عبر نافذة الحفظ الأصلية.

## 🌍 اللغة والمظهر

- الافتراضي **العربية (RTL)** مع إمكانية التبديل **للإنجليزية (LTR)** — كل النصوص مترجمة، والأرقام لاتينية (`0123`) في اللغتين بالتصميم.
- 4 ثيمات (النيل، الدافئ، منتصف الليل، الأكاديمي) × فاتح/داكن، ووضع تباين عالٍ، وساعة 12/24، واختيار بداية الأسبوع. التواريخ تُعرض بصيغة `DD-MM-YYYY`.

## ⌨️ اختصارات الإنتاجية

- `Ctrl+K` (أو `Cmd+K`) — لوحة الأوامر: بحث وتنقل وإنشاء سريع
- نوافذ الإنشاء العامة — إضافة طالب/دفعة/مصروف من أي صفحة
- تراجع عن الحذف من التنبيه (Toast) بعد كل عملية حذف
